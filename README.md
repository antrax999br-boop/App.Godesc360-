## 🛠️ Tecnologias Utilizadas

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Motion, Vite.
- **Backend Microservidor:** Node.js 20 LTS, Express, @whiskeysockets/baileys, Nodemailer, PM2.
- **Banco de Dados & Realtime:** Supabase / PostgreSQL.
- **Servidor Web & Proxy Reverso:** Nginx com suporte a WebSockets e SSL Let's Encrypt.
