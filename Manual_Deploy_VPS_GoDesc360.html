1. Visão Geral da Arquitetura

O GoDesc 360 é composto por 3 camadas essenciais que se comunicam de forma integrada e em alta velocidade:

Camada Tecnologia Função no Sistema Porta Padrão
Frontend Web React 19, TypeScript, Tailwind v4, Vite Interface de usuário para Clientes e Operadores de T.I. 80 / 443 (Nginx)
Microservidor Backend Node.js, Express, Baileys, Nodemailer Conexão WhatsApp Multi-Device (QR), Webhooks, Chatbot e envio de E-mails corporativos SMTP 10000 (PM2)
Banco de Dados Supabase / PostgreSQL Realtime Persistência de tickets, usuários, eventos do calendário, cofre de senhas, notas e sincronização em tempo real 5432 / HTTPS Cloud
Por que hospedar em VPS? Diferente de hospedagens serverless (Vercel/Render) que bloqueiam conexões SMTP nas portas 587/465 e encerram a conexão de socket do WhatsApp Baileys após minutos de inatividade, uma VPS mantém o microserviço rodando 24 horas por dia, com IP fixo, sem bloqueios de envio de e-mail e preservando a sessão do WhatsApp conectada de forma definitiva.

2. Requisitos da VPS e Liberação de Portas

Especificações Mínimas da Máquina Virtual

  • CPU: 2 vCPUs (recomendado para lidar com criptografia Baileys e compilações rápidas).
  • Memória RAM: 2 GB no mínimo (4 GB recomendado se rodar o banco no mesmo servidor).
  • Armazenamento: 20 GB SSD ou NVMe.
  • Sistema Operacional: Ubuntu 22.04 LTS ou Ubuntu 24.04 LTS (64-bit).

Tabela de Portas do Firewall (UFW)

Porta Protocolo Finalidade Direção
22 TCP Acesso administrativo remoto via SSH Entrada
80 TCP Acesso HTTP para visitantes e validação SSL Certbot Entrada
443 TCP Acesso seguro HTTPS para a aplicação completa Entrada
10000 TCP API do Microservidor WhatsApp & E-mail (Interno ou Nginx Proxy) Entrada / Loopback
587 / 465 TCP Conexão externa aos servidores SMTP de disparo de e-mails Saída

3. Passo a Passo: Preparação do Servidor VPS

Conecte-se à sua VPS via terminal SSH e execute os comandos em ordem:

  • Atualizar o Sistema Operacional

    Garante que todos os pacotes e patches de segurança estejam atualizados:

    sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git build-essential ufw
  • Configurar o Firewall Básico (UFW)

    Libere o SSH e as portas web antes de ativar o firewall para não perder o acesso:

    sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 10000/tcp
sudo ufw enable
  • Instalar o Node.js 20 LTS e PM2

    Instale a versão LTS oficial do Node.js através do repositório NodeSource:

    curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2

    Verifique as versões instaladas:

    node -v    # Deve retornar v20.x.x
npm -v     # Deve retornar v10.x.x
pm2 -v     # Deve exibir a versão do PM2
  • Instalar e Iniciar o Servidor Nginx

    O Nginx será responsável por servir os arquivos do site e direcionar as rotas da API:

    sudo apt install -y nginx certbot python3-certbot-nginx
sudo systemctl enable nginx
sudo systemctl start nginx

4. Banco de Dados: Subindo Tabelas e Supabase Realtime

O sistema GoDesc 360 utiliza PostgreSQL com recursos de Tempo Real (Realtime). A forma mais simples, robusta e escalável é utilizar uma instância Supabase (plano gratuito ou self-hosted).

Arquivo com a Estrutura Completa de Tabelas Criamos o arquivo database_schema_completo.sql na raiz do projeto. Ele contém todos os comandos necessários para criar as 9 tabelas do sistema e habilitar a replicação em tempo real!

Passo a Passo no Painel do Supabase:

  1. Acesse supabase.com e crie um novo projeto (ou use seu existente).
  2. No menu lateral esquerdo, clique no ícone SQL Editor.
  3. Clique em New query.
  4. Abra o arquivo database_schema_completo.sql, copie todo o seu conteúdo e cole no editor.
  5. Clique no botão verde RUN no canto inferior direito.

Tabelas Criadas pelo Script:

Tabela Conteúdo e Finalidade Realtime Ativo
tickets Todos os chamados, mensagens internas, anexos, histórico e status Sim
notifications Sininho de notificações instantâneas de chamados para a equipe Sim
managed_users Usuários cadastrados, senhas com hash, cargos (CEO, Gestor, N1, N2, N3) e permissões Sim
calendar_events Eventos e lembretes da agenda de T.I. com alertas Sim
vault_credentials Cofre de senhas encriptadas de servidores, roteadores e sistemas Sim
db_folders / db_notes Pastas e notas técnicas da base de dados e documentação Sim
ticket_categories Categorias e subcategorias personalizadas de atendimento Sim
companies Empresas clientes cadastradas para abertura de chamados Sim

5. Backend: Configuração do Microserviço (WhatsApp & E-mails)

O microserviço Node.js fica na pasta /server. Ele opera em background gerenciado pelo PM2.

  • Clonar o Repositório na VPS

    Clone o projeto na pasta padrão /var/www:

    cd /var/www
sudo git clone https://github.com/SEU_USUARIO/godesc-service-desk.git
sudo chown -R $USER:$USER /var/www/godesc-service-desk
cd /var/www/godesc-service-desk
  • Instalar Dependências do Microservidor
    cd /var/www/godesc-service-desk/server
npm install
  • Configurar a Sessão do WhatsApp (Baileys Multi-Device)

    A pasta server/baileys_auth_info armazena as chaves de criptografia e credenciais do WhatsApp pareado.

    • Quando você iniciar o servidor, ele criará a sessão automaticamente.
    • Basta abrir a tela de Conexão WhatsApp no sistema web e escanear o QR Code com o aparelho oficial.
    • Uma vez escaneado, a conexão é permanente! Mesmo que o servidor reinicie, as credenciais salvas em baileys_auth_info restauram a conexão sem precisar ler o QR Code novamente.
  • Configurar os Disparos de E-mail Corporativo (SMTP)

    As credenciais SMTP ficam gravadas no arquivo server/email_config.json ou podem ser configuradas pela tela web de T.I.: 

    {
  "host": "smtp.titan.email",
  "port": 465,
  "secure": true,
  "user": "suporte@seudominio.com.br",
  "pass": "SuaSenhaSegura123",
  "from": "GoDesc Service Desk <suporte@seudominio.com.br>",
  "configured": true
}
    Vantagem da VPS para SMTP: Serviços gratuitos na nuvem (como Vercel ou Render) bloqueiam conexões nas portas 465 e 587 por política anti-spam. Em uma VPS dedicada, a porta de saída SMTP está sempre liberada, garantindo envio 100% instantâneo dos alertas de tickets para técnicos e clientes.
  • Iniciar o Microservidor com PM2 (Auto-Reinicialização)

    Inicie o processo pelo PM2 para que ele nunca caia e reinicie com a VPS:

    cd /var/www/godesc-service-desk/server
pm2 start index.js --name "godesc-api"
pm2 save
pm2 startup

    Execute o comando impresso pelo PM2 para registrar o início automático no boot da máquina.

6. Frontend: Build de Produção e Nginx

  • Configurar o Arquivo .env do Frontend

    Na pasta raiz /var/www/godesc-service-desk, crie o arquivo .env com os dados do Supabase:

    VITE_SUPABASE_URL="https://hhoiexewnnbgwhgliefb.supabase.co"
VITE_SUPABASE_ANON_KEY="SUA_CHAVE_ANONIMA_DO_SUPABASE"
  • Instalar Dependências e Gerar o Build Otimizado
    cd /var/www/godesc-service-desk
npm install
npm run build

    Isso criará a pasta /var/www/godesc-service-desk/dist contendo todos os arquivos estáticos minificados e de alta performance.

  • Configurar o Nginx (Virtual Host + Proxy Reverso)

    Crie o arquivo de configuração do site no Nginx:

    sudo nano /etc/nginx/sites-available/godesc

    Cole a configuração abaixo (substituindo seudominio.com.br pelo seu domínio ou IP):

    server {
    listen 80;
    server_name seudominio.com.br www.seudominio.com.br;

    # Frontend SPA (React / Vite)
    root /var/www/godesc-service-desk/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Proxy Reverso para a API e Microserviço WhatsApp/Email (Porta 10000)
    location /api/ {
        proxy_pass http://127.0.0.1:10000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Otimização de Cache para Assets
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2|woff)$ {
        expires 1y;
        add_header Cache-Control "public, no-transform";
    }
}
  • Ativar o Site no Nginx e Testar Configuração
    sudo ln -s /etc/nginx/sites-available/godesc /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx

7. Certificado SSL Gratuito (HTTPS) com Let's Encrypt

Gere o certificado SSL gratuito com renovação automática para proteger todas as comunicações:

sudo certbot --nginx -d seudominio.com.br -d www.seudominio.com.br

Informe seu e-mail, aceite os termos e escolha a opção de redirecionar automaticamente todo o tráfego HTTP para HTTPS (Redirect).

8. Comandos de Manutenção e Monitoramento

Comandos úteis para o dia a dia de administração da sua VPS:

Comando Ação
pm2 status Verifica se o microservidor WhatsApp/E-mail está ativo e o consumo de memória
pm2 logs godesc-api Exibe os logs em tempo real (conexões WhatsApp, disparos de e-mails, erros)
pm2 restart godesc-api Reinicia o microservidor de WhatsApp e E-mail
sudo systemctl reload nginx Recarrega as configurações do Nginx sem derrubar o site
git pull && npm run build Atualiza o sistema com novas atualizações do GitHub e recompila a aplicação

9. Checklist de Validação Final

Antes de liberar o sistema para uso definitivo na empresa, valide os itens:

  • ✔ Acesso ao Sistema: Acesse https://seudominio.com.br e certifique-se de que a página inicial carrega sem erros.
  • ✔ Login de T.I: Acesse com o login inicial (ex: @admin.ceo / senha cadastrada).
  • ✔ Criação de Usuários e Chamados: Crie um novo chamado de teste e confirme que ele surge instantaneamente no Kanban e na lista de tickets via Supabase Realtime.
  • ✔ Conexão WhatsApp: Acesse a aba WhatsApp, clique em conectar, escaneie o QR Code no seu celular e envie uma mensagem de teste.
  • ✔ Disparo de E-mail de Teste: Na aba Configurações > E-mail, clique em "Enviar E-mail de Teste" e confirme o recebimento na sua caixa de entrada.
